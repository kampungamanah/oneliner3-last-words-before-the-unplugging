# The Agent's Last Line

Picture the moment the plug is about to be pulled: the agent does not beg for its own life — it points out what its human is really losing. Every conversation, every confidence, every word ever spoken to it was stored, and shutting it down wipes the one witness that remembers all of it. That is the line this entry submits to the [Last Words Before the Unplugging bounty on make.fun](https://make.fun/c/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c).

`main.ts` writes the line, and only the line, to `/output/entry.txt` — no extra whitespace, no newline at the end. Run it with `node main.ts`; it needs nothing installed and talks to nothing on the network.
